# ZERO AGENT

**휴대폰·다른 PC에서 접속할 웹 주소가 필요하면 [웹 배포 안내](DEPLOY.md)를 따르세요.** 개발 환경 게시와 웹사이트 배포는 별도이며, 공개 주소는 호스팅 서비스에서 발급됩니다. `render.yaml`과 `Dockerfile`이 포함되어 있습니다.

시장·뉴스·리스크 분석을 합쳐 판단하고 모의 계좌에 기록하는 개인 리서치 터미널입니다. Tauric Research의 [TradingAgents](https://github.com/TauricResearch/TradingAgents)에서 소개한 역할 분담 구조에 착안한 독립적인 첫 구현입니다. 해당 라이브러리를 설치하거나 게시물의 수익 결과를 재현한 프로젝트는 아닙니다.

## 바로 실행

Node.js **24.5 이상**이 필요합니다. 이 클라우드 환경에는 Node.js 24가 준비되어 있습니다.

```bash
cd /workspace/Zero-Agent
npm ci --cache /workspace/.cache/npm
npm run dev
```

서버는 기본적으로 `127.0.0.1`의 **3000번 포트**에서 개발 화면과 API를 함께 제공합니다. 소스 변경은 Vite를 통해 화면에 반영됩니다. 백엔드를 수정하면 개발 서버를 다시 시작하세요.

배포용 빌드와 실행:

```bash
npm run build
npm start
```

처음에는 **데모 → 분석 실행**을 선택하세요. API 키와 외부 연결 없이 작동하며, 체결 조건을 만족하면 $10,000의 모의 계좌에 주문이 기록됩니다. 자동 분석은 버튼으로 활성화하며, 첫 실행은 5분 후입니다. 서버를 종료하거나 재시작하면 자동 분석은 꺼집니다.

## 동작하는 기능

- **데모 데이터:** 120개 시간봉과 명시적으로 표시된 샘플 뉴스. 계좌는 실제 시세 계좌와 분리됩니다. 가격은 매시간 같은 결정적 시나리오로 생성되므로 투자 성과 검증에 사용하지 않습니다.
- **실제 데이터:** Coinbase Exchange의 BTC/USD, ETH/USD, SOL/USD 현물 가격·시간봉과 BBC Business 글로벌 경제 RSS. 뉴스는 종목 전용 피드가 아니며, 종목과의 관련성은 AI 분석 대상입니다.
- **세 분석 역할:** 시장의 SMA 20·50 / 단순 14기간 RSI / 시간 수익률 표준편차, 뉴스 맥락, 현금·변동성·보유 비중을 각각 검토합니다.
- **키 없는 모드:** 시장·리스크는 공개된 결정적 규칙으로 분석하고, 뉴스는 감성을 추정하지 않고 중립으로 처리합니다. 화면에 `RULE-BASED`를 표시합니다.
- **AI 연결 모드:** OpenAI API에 세 역할의 독립적인 구조화 응답을 요청합니다. 시장 50%, 뉴스 20%, 리스크 30%로 가중 합산하고, 리스크의 관망 의견은 주문 판단을 관망으로 바꿉니다. API 오류나 응답 검증 실패 시 주문을 기록하지 않습니다.
- **현물 모의 계좌:** 비용을 반영한 평균 단가, 미실현·실현 손익, 평가액 이력, 거래 CSV 내보내기, 계좌별 초기화.
- **자동 분석:** 프로세스가 실행 중일 때 선택한 자산 하나를 5분마다 분석합니다. 데이터 소스나 자산을 바꾸면 화면에서 자동 분석을 중지합니다.
- **대시보드:** 데스크톱·모바일 레이아웃, 캔들/선 차트, 24시간/5일 범위, 에이전트 근거, 포지션, 체결 히스토리.

의견 강도는 모델 또는 규칙의 의견 수준이며 검증된 성공 확률이 아닙니다. 이 버전은 **모의투자 전용**이며 실제 주문용 증권사·거래소 API는 연결하지 않습니다.

## AI 연결 (선택)

로컬에서는 `.env.example`을 `.env`로 복사하고 키를 로컬에만 입력하세요. 클라우드에서는 환경 설정의 비밀 값 기능을 사용해 `RESEARCH_API_KEY`를 `api.openai.com` 대상으로 연결할 수 있습니다. 채팅·커밋·클라이언트 코드에 키를 넣지 마세요. `.env`와 데이터 폴더는 Git에서 제외됩니다.

| 변수                      | 기본값         | 의미                                                       |
| ------------------------- | -------------- | ---------------------------------------------------------- |
| `RESEARCH_API_KEY`        | 없음           | OpenAI API 키. 없으면 규칙 모드                            |
| `RESEARCH_MODEL`          | `gpt-4.1-mini` | 구조화 JSON 응답을 지원하는 OpenAI 모델                    |
| `HOST`                    | `127.0.0.1`    | HTTP 바인딩 주소                                           |
| `PORT`                    | `3000`         | HTTP 포트                                                  |
| `DATA_DIR`                | `.data`        | SQLite 보관 폴더                                           |
| `DASHBOARD_PASSWORD`      | 없음           | 공개 배포용 브라우저 로그인 비밀번호. 사용자 이름은 `zero` |
| `DASHBOARD_AUTH_REQUIRED` | `0`            | `1`이면 비밀번호 없이는 서버 시작 거부                     |

일반 로컬 실행에서는 기존 `OPENAI_API_KEY`도 인식합니다. 클라우드 비밀 변수에는 플랫폼의 예약어 제한을 피하는 `RESEARCH_API_KEY`를 사용하세요. 키가 존재하면 데모에서도 AI 호출이 활성화됩니다. 분석 1회는 요청 **3건**이며 별도 API 비용이 발생합니다. 연결 실패를 숨기거나 규칙 모드로 조용히 대체하지 않습니다. 모델 제공자에게 선택한 자산의 시세·뉴스 제목·모의 포트폴리오가 전달됩니다.

실제 API 키가 없는 환경에서는 키 없는 경로와 모의 API 응답으로 AI 프로토콜을 검증할 수 있지만, 실제 모델 인증·응답은 키를 연결한 후 확인해야 합니다.

## 모의 주문 규칙

| 규칙         | 적용                                                               |
| ------------ | ------------------------------------------------------------------ |
| 시작 자금    | 데이터 소스별 $10,000                                              |
| 1회 매수     | 총 평가 자산의 최대 10%, 최소 $10                                  |
| 종목별 비중  | 비용을 반영한 체결 후 평가 자산의 최대 25%                         |
| 매도         | 기존 수량의 절반; 잔액이 $1 미만이면 전량. 공매도 없음             |
| 수수료       | 매수·매도 각각 0.10%                                               |
| 슬리피지     | 매수 +0.05%, 매도 −0.05%                                           |
| 의견 강도    | 65% 미만은 체결 차단                                               |
| 시세         | 2분 초과 또는 미래 시각 이상 시 체결 차단                          |
| 재주문       | 자산·계좌별 5분 대기                                               |
| 일 손실 한도 | UTC 시작 평가액 대비 −3%에서 신규 매수 차단; 비중 축소 매도는 허용 |

손실 한도는 기록된 평가액으로 계산합니다. 해당 날짜 시작 전 마지막 평가액을 사용하며, 없으면 최초 평가액을 사용합니다. 실시간 손절 주문이나 체결 유동성·호가창 시뮬레이션은 포함하지 않습니다. 체결은 조회한 단일 가격에 비용을 더해 계산합니다. 포트폴리오의 시세 시각을 함께 표시하며, 새 분석 시에는 보유 자산의 시세도 갱신합니다.

## 검증

```bash
npm run check
npm test
npm run build
```

테스트는 임시 SQLite / 메모리 DB를 사용해 사용자 계좌를 변경하지 않습니다. 비용·비중·손실 한도·시세 지연·공매도 차단·원자적 기록·영속성·데이터 소스 분리·API 검증·CSV·자동 분석 설정을 확인합니다.

서버가 실행 중일 때 상태와 대표 데이터를 확인할 수 있습니다.

```bash
curl --fail http://127.0.0.1:3000/api/health
curl --fail 'http://127.0.0.1:3000/api/market?mode=demo&symbol=BTC-USD'
curl --fail 'http://127.0.0.1:3000/api/market?mode=live&symbol=BTC-USD'
```

외부 데이터 연결이 실패하면 오류를 표시하며 데모 데이터로 대체하지 않습니다. 뉴스만 실패하면 시세는 유지하고 뉴스 누락 경고를 표시합니다.

## 구조와 보관

```text
src/main.ts          대시보드·차트·사용자 동작
src/style.css        반응형 화면
server/index.ts      HTTP API·자동 분석·정적 파일 / Vite
server/market.ts     데모·Coinbase·BBC RSS·지표
server/agents.ts     세 분석 역할·OpenAI·의견 종합
server/store.ts      SQLite·포트폴리오·비용·주문 한도
server/types.ts      공통 데이터 형식
tests/               엔진 및 HTTP 통합 검증
.data/               실행 시 생성되는 계좌 DB (Git 제외)
```

의존성은 `package-lock.json`으로 고정합니다. 계좌·판단·체결·평가 이력은 `.data/zero-agent.sqlite`에 보관되므로 프로세스 재시작에도 유지됩니다. 데이터를 옮길 때는 서버를 중지하고 `.data` 전체를 백업하세요. 클라우드의 새 머신 복원은 환경 스냅샷 보관 정책에 따릅니다.

네트워크가 제한된 환경에서 필요한 도메인은 `registry.npmjs.org`, `api.exchange.coinbase.com`, `feeds.bbci.co.uk`이며, AI 연결에는 `api.openai.com`이 추가됩니다. Node의 `--use-env-proxy`로 제공된 프록시를 사용하고 TLS 검증을 유지합니다.

현재 서버는 개인 개발 환경을 전제로 하며 기본적으로 로컬 주소에 바인딩됩니다. 공개 배포 구성은 비밀번호 인증을 적용하며, Render가 HTTPS를 제공합니다. 독립 머신에서 24시간 운영하려면 계속 실행되는 서버, 영속 데이터 저장과 프로세스 관리가 필요합니다. 상세 조건은 [웹 배포 안내](DEPLOY.md)를 확인하세요.
